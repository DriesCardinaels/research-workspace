# Standalone interface concepts

`toolbar-designs.html`, `toolbar-themes.html` and
`project-navigation-designs.html` are design exploration pages. Open the desired
HTML file directly in a browser. They are not loaded by `static/index.html` and
do not define supported application interfaces.

To add a concept, create a standalone HTML page using synthetic content, explain
its purpose here and compare the relevant states, including narrow layouts and
keyboard/focus behavior. Do not link personal research files. Implement an adopted
concept through the active [Tool/file-type guide](../../static/README.md), with
production contracts and regression checks; do not copy application state into a
second maintained mock runtime.

The [settings provider survey](settings-research.md) records the references
behind the categorized layout adopted in Workbench.
