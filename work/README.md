# Development experiments and validation output

This directory is outside the active runtime. Do not import it from application
code or load its pages through application bootstrap.

- `mockups/` contains standalone design concepts; see its [guide](mockups/README.md).
- `verification/` contains visual development evidence, not regression fixtures.
- `api-validation/` is generated by `tools/validate_api.py` and ignored by Git.

Add an experiment in a named subdirectory with a README explaining its question,
inputs, launch procedure and whether the result was adopted. Use synthetic data
and relative asset paths. Move adopted behavior into its owning feature and test
it there; a screenshot or mockup does not prove runtime correctness. Keep generated
reports, personal paths and manuscripts out of public commits.
